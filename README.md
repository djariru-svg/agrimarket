# AgriMarket RW

This project has been migrated from PHP + JSON files to a Node.js server using SQLite.

## Getting started

1. Install dependencies:
   npm install
2. Start the app:
   npm start
3. Open the app in your browser at:
   http://localhost:3000

## Notes

- The frontend assets in `agrimarket-rw/` remain available without changes.
- The backend API routes keep the legacy `*.php` naming for compatibility with the existing frontend client.
- All application data is stored in SQLite (`data/agrimarket.db`) instead of JSON files.
